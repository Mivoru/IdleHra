## 4. Cloud-environment traps (Claude Code on the web)

- **Docker daemon:** `sudo setsid nohup dockerd >> /tmp/dockerd.log 2>&1 < /dev/null &`. A `dockerd` started from a subagent's shell dies when that agent ends, and it killed a full-suite run mid-way (hundreds of tests failing in 1 ms with `EndOfStream`).
- **Killing processes:** never `pkill -f FolkIdle.Server` or `pgrep -f "dotnet run ..."`; the pattern matches your own shell and kills it (exit 144). Find the PIDs with `ps -eo pid,args | grep ... | grep -v grep` in one call and `kill` them in the next.
- **.NET SDK:** `sudo apt-get update && sudo apt-get install -y dotnet-sdk-8.0`. dot.net and builds.dotnet.microsoft.com are blocked by the proxy.
- **Playwright:** it wants `chromium_headless_shell-1234`, and 1194 is installed. The fix is a symlink: `/opt/pw-browsers/chromium_headless_shell-1234/chrome-headless-shell-linux64` pointing to `.../chromium_headless_shell-1194/chrome-linux`, plus `chrome-headless-shell` pointing to `headless_shell`.
- **Local stack:** `docker run` `postgres:16` (password `postgres`, db `folkidle_dev`, port 5432) and `redis:7-alpine` (port 6379), then `--migrate`, `--seed-dev`, and run the server with `FOLKIDLE_WEB_ORIGINS=http://localhost:5173 FOLKIDLE_DEV_TOOLS=1 FOLKIDLE_DELVE_DEEP=on FOLKIDLE_BOSS_MINIGAME=wheel`. Run Vite on port 5173.
- **Fixture and exercise:** since #116 the fixture survives an exercise run. On a fresh database, create a guild for the fixture once (`POST /api/v1/guilds/create {"guildName":"Dev Guild"}`) or the cosmetic-market step times out.
- **Git LFS:** upload to GitHub LFS is 403 from the cloud, so PNGs cannot be committed there. `docs/screenshots/2026-09-30/*.png` are plain blobs; on the PC run `git add --renormalize docs/screenshots/2026-09-30; git commit; git push`. In worktrees, PNGs show as modified; that is LFS noise, not an edit (`git update-index --assume-unchanged`).
- **Production:** `folkidle.duckdns.org` is not reachable from the cloud session. Deploys and `smoke:screens` against production run on the owner's PC.
