# FolkIdle
#
# There was no robots.txt at all, which is not the same as an empty one: the
# SPA fallback answered /robots.txt with index.html, so a crawler asking what
# it may read got a page of HTML and a 200. Everything here is public and
# there is nothing to hide, so the answer is simply yes.
#
# A real file rather than a Caddy route on purpose - Vite copies public/ into
# the build, and `try_files {path} /index.html` finds it before the fallback
# runs. See ops/oracle/Caddyfile on why the ordering of those handle blocks is
# load-bearing.
#
# The hostname settled on folkidle.cz (2026-10-08). The sitemap lists the one
# page and the privacy policy; its real use is that Search Console and
# Seznam Webmaster accept it as "here is the site", which is what gets a new
# domain crawled in days rather than whenever a link happens to be found.

User-agent: *
Allow: /

# The API and the game data are not pages. Crawling them costs the server real
# work and produces nothing anyone would want in a search result.
Disallow: /api/
Disallow: /gamedata/

Sitemap: https://folkidle.cz/sitemap.xml
